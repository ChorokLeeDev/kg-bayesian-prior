\subsection{Setup}

\paragraph{Datasets.}
WN18RR (40,943 entities, 11 relations), FB15k-237 (14,541 entities, 237 relations), and YAGO3-10 (123,161 entities, 37 relations).

\paragraph{Task.}
OOD detection: distinguish ID test triples from random tail corruptions.
Following standard protocol, for each test triple $(h, r, t)$, the OOD version is $(h, r, t')$ where $t' \sim \text{Uniform}(\mathcal{E})$.

\paragraph{Baselines.}
\begin{itemize}
    \item \textbf{GP-only}: Vanilla GP-KGE uncertainty (Eq.~\ref{eq:gp_uncertainty})
    \item \textbf{Coverage-only}: Structural uncertainty without GP
    \item \textbf{MC Dropout}: Standard uncertainty via test-time dropout
    \item \textbf{Deep Ensemble}: Variance across 5 independently trained models
\end{itemize}

\paragraph{Metric.} AUROC (higher = better OOD detection).

\paragraph{Training.} 50 epochs, embedding dimension 100, batch size 2048, 3 seeds.

Table~\ref{tab:main} shows the main results.
CAGP achieves 0.87--0.96 AUROC across all datasets, significantly outperforming both single-signal baselines.

I define \emph{synergy} as the relative improvement over the best single component:
\begin{equation}
    \text{Synergy} = \frac{\text{AUROC}_{\text{CAGP}} - \max(\text{AUROC}_{\text{GP}}, \text{AUROC}_{\text{Cov}})}{\max(\text{AUROC}_{\text{GP}}, \text{AUROC}_{\text{Cov}})}
\end{equation}

\textbf{Key observations:}
\begin{enumerate}
    \item \textbf{Consistent synergy}: CAGP improves over the best single component by 14--32\% across all datasets.
    \item \textbf{Neither signal dominates}: GP wins on YAGO3-10 (0.824 vs 0.760), Coverage wins on FB15k-237 (0.821 vs 0.749).
    \item \textbf{Optimal $\alpha \approx 0.5$}: The mixing coefficient converges to $\approx$0.5 across all experiments (initialized at 0.5, gradient updates preserve this), suggesting equal contribution from both signals.
    \item \textbf{Remarkably stable}: CAGP achieves std = 0.0001 on YAGO3-10 across seeds.
\end{enumerate}

Table~\ref{tab:theorem} validates Theorem~\ref{thm:coverage_auroc}.
The closed-form prediction matches observed AUROC within 3.6\% error, confirming the theoretical framework (visualization in Appendix~\ref{app:extended}).

\textbf{Critical finding}: Only 54\% (WN18RR) and 69\% (FB15k-237) of ID test triples have both entities covered.
This explains why coverage alone is limited---nearly half of ID triples ``look like'' OOD to coverage.
GP variance helps by capturing embedding quality for these uncovered entities.

\subsection{Ablation: Why Both Components?}

\begin{table}[t]

Table~\ref{tab:ablation} confirms that both components are necessary.
Setting $\alpha = 0$ or $\alpha = 1$ reduces to single-signal baselines, losing 17--33\% AUROC.
