The central insight of this work is that OOD detection in knowledge graphs requires distinguishing \emph{what kind} of distribution shift has occurred---a distinction invisible to relation-agnostic uncertainty estimators.
By decomposing uncertainty into semantic and structural components, we predict complementary failure modes: semantic variance captures emerging entities while structural coverage captures novel relational contexts, each compensating where the other fails.
The key empirical validation comes from temporal KGs with ground-truth splits: ICEWS14 (0.993 AUROC) and ICEWS18 (0.987 AUROC). On these datasets, CAGP outperforms all baselines, confirming that the decomposition's predictions hold when the coverage signal is decoupled from the OOD definition. The three static benchmarks validate the decomposition's structural predictions---per-category AUROC matches theoretical predictions within 0.002---rather than demonstrating independent detection capability (novel-context AUROC $= 1$ is by construction on those splits). The improvement is largest on emerging entities (+8--12pp), confirming that the semantic signal provides genuine complementary value when properly trained.
The decomposition is architecture-agnostic (DistMult, TransE, ComplEx; Appendix~\ref{app:architectures}) and computationally lightweight (coverage is precomputed once).
These properties make it applicable to domains where KG reliability is critical, such as drug interaction prediction, clinical decision support, and recommender systems.

\paragraph{Practical implications.}
Our analysis yields three actionable recommendations: (1)~\emph{Always track entity-relation coverage} alongside embedding uncertainty---this is a zero-cost addition (a hash table lookup) that catches the failure mode invisible to learned variances. (2)~\emph{Use reparameterization sampling} in the scoring function when training variational KG embeddings; without it, KL regularization collapses variances, making semantic uncertainty meaningless. (3)~\emph{Report per-category OOD metrics} (emerging vs.\ novel contexts), not just overall AUROC---overall numbers obscure complementary failure modes (Table~\ref{tab:complementarity}).

\paragraph{Scalability considerations.}
CAGP's coverage matrix $\mathbf{C} \in \{0,1\}^{|\mathcal{E}| \times |\mathcal{R}|}$ requires $O(|\mathcal{E}| \times |\mathcal{R}|)$ memory. For our evaluated datasets (FB15k-237: 13MB dense, $<$1MB sparse; YAGO3-10: 18MB dense, $<$1MB sparse), this is negligible. For web-scale KGs, sparse storage (hash tables storing only observed pairs) reduces memory to $O(|\mathcal{T}|)$ with $O(1)$ inference. We also explored learned relation-conditioned variance via multi-layer perceptron, but found explicit coverage simpler and equally effective. CAGP provides interpretability and simplicity suitable for domain-specific KGs with $<$1M entities; empirical evaluation on billion-triple KGs remains future work.

\paragraph{Limitations.}
The static benchmark results validate the decomposition's structural predictions (per-category AUROC within 0.002 of theory) rather than independent detection capability: novel-context AUROC $= 1$ is by construction because the split definition uses coverage (Remark~\ref{rem:circularity}). This is a feature of the decomposition framework---it confirms the signals separate as designed---but means the static results provide diagnostic validation, not performance claims. ICEWS14 and ICEWS18 break this coupling with ground-truth temporal splits; together they strengthen generalizability. We tested bilinear scoring as a step toward relation-aware architectures (Appendix~\ref{app:bilinear}); full message-passing models (R-GCN, CompGCN) remain untested.
CAGP uses fixed equal weighting ($\alpha{=}0.5$), which is near-optimal across all datasets (Appendix~\ref{app:alpha_sensitivity}). The robustness to $\alpha$ reflects the complementary nature of the signals; an adaptive mechanism for datasets with extreme OOD compositions remains future work.
Reparameterization sampling is essential: without it, KL regularization collapses entity variances (see error analysis), a pitfall that likely affects other probabilistic KG embedding methods.
Coverage is binary; the approach assumes transductive settings; assumption A4 is violated or borderline on all three benchmarks ($\Delta \geq 1.0$), so formal guarantees should be interpreted qualitatively.
An oracle selective prediction analysis (test-set threshold; see Appendix~\ref{app:selective}) shows up to 43\% error reduction at 85\% coverage; validating this with held-out threshold selection remains future work.

\paragraph{Future directions.}
(1)~\emph{GNN encoders.} We tested relation-conditioned bilinear scoring ($h^\top W_r t$ with basis decomposition; Appendix~\ref{app:bilinear}), which does not improve entity-level OOD detection. The open question is whether full message-passing architectures (R-GCN~\citep{schlichtkrull2018modeling}, CompGCN~\citep{vashishth2019composition}) produce relation-aware entity variance through neighborhood aggregation.
(2)~\emph{Adaptive mixing.} The flat $\alpha$ landscape (Appendix~\ref{app:alpha_sensitivity}) reflects non-overlapping failure modes; per-relation $\alpha_r$ could benefit datasets with heterogeneous signal strengths across relations.
(3)~\emph{Inductive settings.} Coverage is undefined for entities absent from training; hybrid approaches combining graph-structural features with coverage may extend CAGP to inductive KG completion.
(4)~\emph{Scalability.} Sparse coverage storage and streaming updates would enable deployment on evolving, web-scale KGs.
(5)~\emph{Applications.} In retrieval-augmented generation, $U_{\text{str}}$ can flag queries lacking relational grounding while $U_{\text{sem}}$ flags poorly-constrained entities, enabling targeted abstention. The decomposition supports differentiated interventions: high $U_{\text{sem}}$ (emerging entity) suggests collecting more data about the entity, while high $U_{\text{str}}$ (novel context) suggests the model lacks relational experience and predictions should be withheld.
