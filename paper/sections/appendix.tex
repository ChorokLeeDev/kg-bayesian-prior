\section{Implementation Details}
\label{app:implementation}

\paragraph{Hyperparameters.}
Embedding dimension $d=200$ (FB15k-237) or $d=100$ (others).
Inducing points $P=500$, eigenvectors per relation $k=50$.
Adam optimizer, learning rate $10^{-3}$, batch size 1024, KL weight $\beta=10^{-3}$.
All experiments averaged over 3 seeds.

\paragraph{Eigendecomposition.}
We compute top-$k$ eigenvectors of each $\mat{L}_r$ using \texttt{scipy.sparse.linalg.eigsh}.
Relations with $<$100 edges use a global kernel fallback.
